# Backlog

ユーザーが `/backlog <要件>` と入力したら、`docs/backlog.md` の `## 未整理` セクション末尾に箇条書きとして追記する。

## ワークフロー

1. `docs/backlog.md` を読み込む
2. 引数として渡された要件を、簡潔な日本語の箇条書き（`- ` 始まり）に整形する
3. `## 未整理` セクションの末尾に追記する（Edit ツールを使用）
4. 追記した内容をユーザーに報告する

## ルール

- 引数が雑でも意図を汲み取り、既存の箇条書きと同じトーン・粒度で書く
- 1つの引数から複数項目が読み取れる場合は複数行に分けてよい
- 既存の項目と明らかに重複する場合はユーザーに確認する
- バックログの既存項目を削除・編集しない（追記のみ）
